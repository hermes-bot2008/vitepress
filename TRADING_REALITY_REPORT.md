### 3. Pourquoi le Scalping Échoue?

#### A. Les Coûts de Transaction

```
EXEMPLE: 200 trades/mois en scalping

Spread:       $2/trade × 200 = $400/mois
Commission:   $1/trade × 200 = $200/mois
Slippage:     $1/trade × 200 = $200/mois
─────────────────────────────────────────
TOTAL:                          $800/mois
─────────────────────────────────────────

Sur un capital de $10,000 = 8% de coûts!
```

**Conclusion:** Il faut gagner 8% juste pour couvrir les coûts!

#### B. Le Profit Factor

Pour être rentable en scalping avec 200 trades/mois:

```
Win Rate requis avec Ratio 1:1 = 58%+
Win Rate requis avec Ratio 1.5:1 = 52%+
Win Rate requis avec Ratio 2:1 = 48%+

NOS RÉSULTATS:
- Win Rate moyen: 40-50%
- Ratio moyen: 0.9:1 (perd plus qu'il gagne!)
```

**Conclusion:** Les conditions ne sont pas remplies!

#### C. La Psychologie

Scalping = Stress maximal:
- 50-200 décisions par jour
- Concentration 8-10h/jour
- Émotions à chaque trade
- Burn-out en quelques semaines

**Impossible à maintenir longtemps!**

## 📊 STRATÉGIE GAGNANTE: QUANTDESK ULTRA SWING

### Configuration Optimale

```python
from quantdesk import MeanReversionStrategy
from quantdesk.risk import RiskManager
from quantdesk.backtesting import Backtester

# Stratégie Swing optimisée
strategy = MeanReversionStrategy(
    symbol="XAUUSD",
    lot_size=0.02,  # 2% du capital
    bb_period=20,
    rsi_oversold=30,
    rsi_overbought=70
)

# Risk management conservateur
risk_manager = RiskManager(
    initial_capital=10000,
    max_daily_loss=100,  # 1% max
    max_drawdown_percent=15,
    max_risk_per_trade=2
)

# Backtest
backtester = Backtester(strategy, 10000)
results = backtester.run(data, risk_manager)
```
